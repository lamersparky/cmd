NO BACKEND REQUIRED

Add a command to the library.

This editor runs in your browser. It loads the current JSON library, adds your entry, and downloads a replacement JSON file. Upload that file to your GitHub repository to publish it.

Format: FLAG | explanation. Leave blank if the command has no common options.
Use COMMAND | DESCRIPTION | SAMPLE OUTPUT. Output is illustrative; it is never executed.

Entry preview

Your command record will appear here.

Publish the change on GitHub Pages

  1. Choose Linux or Windows CMD and fill in the command details.
  2. Click Add to library & prepare download. Your browser downloads the updated linux.json or windows.json.
  3. Open your repository on GitHub and replace the matching file inside data/ with the downloaded file.
  4. Commit the change. GitHub Pages republishes the updated command library automatically.

Why download instead of saving directly? GitHub Pages is static hosting. A public web page cannot safely write to your repository. This editor prepares the updated file without needing a GitHub token or server.
